# Tahqeeq

### is a Kanban (Trello-like) for adding tasks and categorize it into to-do, in-progress, and finished.

<br>

# Techstack
- React.js
- Typescript
- Axios
- React Query
- Zustand (Global state manager)
- @dnd-kit
- Tailwind CSS
- Lucide-React
- react-router

In the future the data will be from laravel
